# Actividad 1: Alicia en el país de las maravillas

## Descripción
Página con tres formularios de práctica de HTML5, CSS3 y JavaScript nativo:
1. Poción mágica: cálculo secuencial y decisiones `if / else if / else`.
2. Merienda: selección de precios con `switch`, cálculo de subtotal, descuento y total.
3. Reina de Corazones: ciclo `for`, clasificación de pares e impares, conteo y sumas.

## Cómo ejecutar
1. Descarga o clona el repositorio.
2. Abre la carpeta `Actividad1_Alicia`.
3. Abre `index.html` en Chrome, Edge o Firefox.
4. Prueba los tres formularios. No necesita servidor ni instalar bibliotecas.

## Regla de cada ejercicio
- Poción: altura final = altura inicial − (ml de poción × 2). La puerta mide 120 cm. Se acepta poción de 0 a 100 ml. Si el cálculo da una altura negativa, se muestra una advertencia y se limita a 0 cm.
- Merienda: té £5, café £7, chocolate £8 y limonada £4. Descuento del 10 % si se compran 4 o más tazas. Máximo 20 tazas.
- Reina: analiza desde 1 hasta el número ingresado, máximo 50.

## Estructura
- `index.html`: estructura y formularios.
- `css/estilos.css`: presentación y adaptación a pantallas pequeñas.
- `js/app.js`: validaciones, funciones, cálculos y eventos.

## Publicación y entrega
1. Crea un repositorio público en GitHub y sube estos archivos.
2. Para publicar la página, entra a Settings > Pages, selecciona la rama `main` y la carpeta `/ (root)` de esta carpeta o publica el contenido de esta carpeta como raíz de un repositorio independiente.
3. Espera a que GitHub Pages genere la URL y comprueba que los tres formularios funcionen.
4. Graba el video de máximo 3 minutos usando el guion `GUION_VIDEO_3_MINUTOS.md`.
5. Añade aquí los enlaces reales de página, repositorio y video antes de entregar.
